🐍 Snake Game in Python

A classic Snake Game built using Python’s turtle graphics library. Control the snake, collect food, increase your score, and avoid colliding with the walls or your own body!

🎮 Features

* 🐍 Classic Snake gameplay
* 🍎 Food collection and score tracking
* 🏆 High-score tracking during gameplay
* ⌨️ Keyboard controls for movement
* 💥 Collision detection with walls and the snake’s body
* 🖥️ Simple graphics powered by Python’s built-in turtle module

🛠️ Technologies Used

* Python 3
* Turtle — graphics and game interface
* Time — timing utilities, if used in the implementation

📋 Requirements

* Python 3 installed on your computer
* No additional packages required if your Python installation includes turtle
